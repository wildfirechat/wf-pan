开源许可

「文档」的在线编辑使用了下列开源软件，特此致谢。

文档编辑引擎
Euro-Office DocumentServerAGPL-3.0

Euro-Office 基于 Ascensio System SIA 开发的 ONLYOFFICE Docs。本系统未修改其程序代码，只调整了字体、配置默认值和容器启动脚本；所用版本见部署包内的《第三方开源许可》。

许可全文 Euro-Office 源码 ONLYOFFICE 源码
字体
Noto Sans SC、Noto Serif SCOFL-1.1
朱雀仿宋（Zhuque Fangsong）OFL-1.1
DejaVu、Liberation 及编辑引擎自带的开源字体各自的开源字体许可
PDF 预览
PDF.jsApache-2.0

手机端只读预览时用它把后端转好的 PDF 逐页画到页面上（手机 WebView 内嵌 PDF 只能显示第一页）。

许可全文 PDF.js 源码
新建文档模板
python-docx、openpyxl、python-pptx生成空白模板MIT
