开源许可

「文档」的在线编辑使用了下列开源软件，特此致谢。

文档编辑引擎：Euro-Office

Euro-Office 基于 Ascensio System SIA 开发的 ONLYOFFICE Docs，按 GNU Affero General Public License v3（AGPL-3.0）发布。 本系统未修改其程序代码，只调整了字体、配置默认值和容器启动脚本。

  • 许可全文：https://www.gnu.org/licenses/agpl-3.0.html
  • 源码：https://github.com/Euro-Office/DocumentServer（所用版本见部署包内的《第三方开源许可》）
  • ONLYOFFICE：https://github.com/ONLYOFFICE/DocumentServer

字体

  • Noto Sans SC、Noto Serif SC —— SIL Open Font License 1.1
  • 朱雀仿宋（Zhuque Fangsong）—— SIL Open Font License 1.1
  • DejaVu、Liberation 及编辑引擎自带的开源字体 —— 各自的开源字体许可

新建文档模板

空白模板由 python-docx、openpyxl、python-pptx（均为 MIT 许可）生成。
